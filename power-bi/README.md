**Project: Retail Sales Performance Analysis Dashboard**
Type: Group project
Tools: Using Microsoft Power BI

The objective of this project is to analyse retail sales data using Microsoft Power BI and transform raw transactional data into meaningful business insights. The project combines multiple datasets through data modelling and relationship creation to produce an interactive business intelligence dashboard.

The dashboard includes DAX calculations, bookmarks, slicers and visualisations to make the report easy to navigate and analyse. A secondary dataset was also included to compare sales trends and support the analysis.

The report aims to support business decision-making by identifying high-performing products, profitable product categories, major customer markets and overall sales trends that can assist management in improving future sales strategies.
